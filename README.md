## Установка и запуск


1. **Клонируйте репозиторий**
   ```bash
   git clone git@github.com:maxborisovp/test_sber_credit_2026.git
   cd test_sber_credit_2026.git
   ```

2. **Создайте и активируйте виртуальное окружение**
    ```bash
    python -m venv venv
    source venv/bin/activate      # Linux/macOS
    venv\Scripts\activate         # Windows
    ```

3. **Установите зависимости**

    ```bash
    pip install -r requirements.txt
    ```

4. **Поместите данные**

    Скопируйте файлы в папку data/.

5. **Запустите программу**

    ```bash
    python main.py
    ```

## Архитектура решения

Пайплайн обработки данных состоит из трёх основных этапов:

1. Классификация типа документа по содержимому (classififcation.py)

    - Вычисление уверенности соответствия типу документа (акт, счет, договор, спецификация) используя llm или по ключевым словам в случае какой-либо ошибки при использовании langchain

    - Определение типа документа, проверяя уверенности по условиям задачи (>0.5 разница со следующим местом ≥ 0.1)


2. Извлечение полей из текста (extraction.py)

    - Отправка запроса и получения ответа от llm в виде json полей из текста

    - Если api ключа нет или возникла какая-либо ошибка поиск полей по регулярным выражениям:
        
        - извлечение даты форматов 01.03.2025 / 1 марта 2025 г. / 03/01/25 и приведение к iso формату

        - извлечение итоговой суммы, путем поиска максимального числа форматов 1 250 000,00 руб. / 1250000.00 ₽ / 1,250,000.00 RUB / Один миллион двести пятьдесят тысяч рублей

        - извлечение ИНН контрагента

        - извлечение контрагента

        - извлечение предмета, путем поиска явного упоминания (Предмет договора: ), извлечения из скобок после глагола(поставить/выполнить ...) извлечения из таблицы, извлечения из пронумерованного списка


3. Проверка соответствия предмета оплаты льготной программе (checking_subject.py)

    - Отправка запроса и получения ответа от llm в виде соответствие, уверенность, краткое объяснение

    - Если api ключа нет или возникла какая-либо ошибка поиск полей по регулярным выражениям:
        
        - Подсчет веса при совпадении ключевых слов, однозначно соответствующей теме сельхоз услуг

        - Подсчет веса при совпадении ключевых слов, однозначно несоотвесвтующей теме сельхоз услуг

        - Формирование соответствия, уверенности, краткого объяснения



## Используемые технологии

| Технология | Назначение | Почему выбрана |
|-------------|-------------|-------------|
| Python 3  | Основной язык программирования | Требование задания, богатая экосистема для анализа данных |
| pytest  | Unit-тестирование | Простой и мощный фреймворк, требование задания |
| langchain + langchain_google_genai  | ИИ-агент | Создание цепочек обработки запросов (цепей) и интеграция с большими языковыми моделями (LLM) Google (например, Gemini) для генерации ответов на естественном языке.| 

## Компромиссы и допущения

1. Определение типа документа по ключевым словам

    Ключевые слова выделены на основе предоставленных данных. Для повышения точности список можно расширить (лежит в config.py).

2. Извлечение полей по регулярным выражениям

    Регулярные выражения фиксированны и врядли покрывают всевозможные случаи.

3. Проверка соответствия предмета оплаты льготной программе

    Ключевые слова выделены на основе предоставленной темы - сельхоз услуги и точно невсеоблемлющи. Для повышения точности список можно расширить (лежит в config.py).

4. Ограничение по количеству токенов/запросов от llm
